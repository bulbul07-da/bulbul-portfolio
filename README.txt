To preview:
1. Keep the assets folder and index.html together.
2. Double-click index.html to open it in a browser.

To publish free using GitHub Pages:
1. Sign in to GitHub and create a new public repository.
2. Upload index.html and the assets folder (including bulbul-profile.jpg).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save.
5. Wait for GitHub Pages to provide the public website URL.
